# Marketing Funnel & Conversion Performance Analysis

## Project Overview

This project analyzes lead conversion performance and marketing funnel efficiency using Python.

## Objectives

* Analyze lead conversion rates
* Identify high-performing lead sources
* Evaluate lead origins
* Measure funnel performance
* Generate actionable business insights

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Dataset

Lead Scoring Dataset from Kaggle.

## Key Insights

* Calculated overall conversion rate
* Identified top-performing lead sources
* Analyzed lead origins
* Created funnel visualizations
* Generated business recommendations
